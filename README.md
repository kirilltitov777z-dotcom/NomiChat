# Nomi — мессенджер в стиле Telegram 🩵

Красивый Android-мессенджер на Kotlin + Jetpack Compose. Сделан под телефон:
вертикальный экран, чистый белый фон, синие акценты, зелёные исходящие пузыри.

## Что есть

- **Чаты** — список диалогов и групп, аватары, онлайн-точки, непрочитанные, поиск, избранное.
- **Диалог** — пузыри сообщений, время, galochki, поле ввода, отправка.
- **Подарки** — 8 ярких PNG-иконок (роза, торт, алмаз, корона, мишка, ракета, мороженое, звезда), баланс монет, выбор получателя, отправка подарка прямо в чат.
- **Контакты** и **Профиль** — список контактов, баланс, настройки.
- Всё работает локально, без сервера и регистрации.

## Сборка

```bash
./gradlew :app:assembleDebug
```

APK собирается в GitHub Actions (артефакт `nomi-debug`).
